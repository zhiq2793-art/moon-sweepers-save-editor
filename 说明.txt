Moon Sweepers 改金币工具
==========================

【最简单：双击 Moon改金币.exe】
  不需要装 Python，这个 exe 自带运行环境，放哪个文件夹都能用。
  第一次双击时 Windows 可能弹「已保护你的电脑」→ 点「更多信息」→「仍要运行」
  （exe 没有数字签名，属于正常提示，不是病毒）

  运行后：
    1. 自动列出所有存档栏位（余额 / 扇区 / 游玩时长）
    2. 输入编号选栏位（直接回车 = 1）
    3. 输入目标金额，支持千分位：500000 或 1,234,567.89
    4. 输入 y 确认
    5. 自动备份 + 写入 + 复核

【备选：双击 改金币.bat】
  功能完全一样，但需要机器上装了 Python 并在 PATH 里。

【命令行/脚本用法】
  moon_tool.py      交互式（同 exe）
  moon_wallet.py    底层命令行：
      python moon_wallet.py inspect --save-dir "…\MoonSessions\slot-1"
      python moon_wallet.py patch   --save-dir "…\slot-1" --target 1000000 --out-dir out

【改之前】
  1. 完全退出游戏（进程里不要有 MoonSweepers.exe，工具也会检测并提醒）
  2. 建议 Steam 里临时关闭这游戏的云同步，避免被云端旧档盖回去
  3. 工具会自动把整个栏位备份成 slot-N.backup-时间戳

【改之后】
  进游戏 → 确认余额 → 正常保存退出一次

【还原】
  删掉现在的 slot-N，把 slot-N.backup-时间戳 改名回 slot-N

【如果 exe 报 "Could not create temporary directory"】
  说明系统临时目录不可写（少见）。解决办法：
    右键「此电脑」→ 属性 → 高级系统设置 → 环境变量，
    把 用户变量 里的 TEMP / TMP 指向一个存在的可写目录（例如 C:\Temp），
    或者改用 改金币.bat（需要 Python）。

【原理（游戏更新后可自查）】
  session.moon = "1PCM" + uint32 解压长度 + uint8(64) + ASCII SHA-256 + gzip(数据)
  解压后数据里，键 "team"（前有 0x04 长度字节）后紧跟 16 字节 .NET Decimal：

      lo(u32) mid(u32) hi(u32) flags(u32)
      scale = (flags >> 16) & 0xFF
      金额   = (lo + mid*2^32 + hi*2^64) / 10^scale

  本机实测 scale = 18。工具只替换 mantissa，保留 scale/flags，
  并重算 SHA-256 与长度字段。
